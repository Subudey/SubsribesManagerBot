# 💳 Subscribes Manager Bot (В ТГ: @subscribes_manager_bot)

> Telegram-бот для удобного учета личных подписок и регулярных расходов.

![Python](https://img.shields.io/badge/Python-3.11+-blue?style=for-the-badge&logo=python)
![aiogram](https://img.shields.io/badge/aiogram-3.x-blue?style=for-the-badge)
![SQLAlchemy](https://img.shields.io/badge/SQLAlchemy-2.0-red?style=for-the-badge)

## 🌟 Основные возможности

* ➕ **Управление подписками:** Удобный добавление, просмотр и мгновенное удаление через Inline-меню.
* 🔔 **Умные уведомления:** Автоматические напоминания за **3 дня** и за **1 день** до даты списания средств.
* 📊 **Кастомные настройки:** Поддержка различных валют.

## 🛠 Технологический стек

* **Language:** Python 3.11
* **Framework:** aiogram 3 (AsyncIO)
* **Database:** SQLite + SQLAlchemy 2.0 (Async)
* **Scheduler:** APScheduler
